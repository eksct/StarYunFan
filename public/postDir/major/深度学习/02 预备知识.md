# 02 预备知识

参考：[《动手学深度学习》第 2 章：预备知识](https://zh-v2.d2l.ai/chapter_preliminaries/index.html)。按原书七节整理，代码使用 PyTorch。

后面的输入数据、模型参数和计算结果，大多要放在张量中处理；训练时还要用到矩阵运算、求导和概率。这一章就是这些基础。

运行代码需要 Python，以及 `torch`、`pandas`、`numpy`。安装命令为 `python -m pip install torch pandas numpy`。每节代码按顺序执行，默认使用 CPU。`import torch` 导入 PyTorch，`print` 用于显示结果，`#` 后面是给人看的注释。

## 02.01 数据操作

### 张量、形状和维度

张量（Tensor）是保存数字的一种数据结构。一个数是标量，一排数是向量，一张数字表是矩阵；继续把这些表叠起来，就能得到更高阶的张量。图片、文本转换成数字后，也能用张量存储。

```python
import torch

x = torch.arange(12)       # 从 0 到 11，共 12 个整数
print(x.shape)             # torch.Size([12])
print(x.ndim)              # 1：只有一个轴
print(x.numel())           # 12：元素总数

X = x.reshape(3, 4)
print(X)
print(X.shape)             # torch.Size([3, 4])
```

`reshape(3, 4)` 把原来的 12 个数排成 3 行 4 列，数值和读取顺序不变。`shape` 是形状，`ndim` 是轴数，`numel()` 是元素总数，这三个量要分清。

形状为 `(2, 3, 4)` 的张量，可以理解为两张 3 行 4 列的表，共 24 个数。它有三个轴。而“三维向量”一般指 `[x₁, x₂, x₃]` 这样有三个分量的向量，在 PyTorch 里它仍然只有一个轴。

重排时可以写 `x.reshape(-1, 4)`，让程序根据总数推算出另一边是 3。一次最多用一个 `-1`，重排前后的元素总数必须相等。

其他常用的创建方式：

```python
print(torch.zeros((2, 3)))              # 全 0
print(torch.ones((2, 3)))               # 全 1
print(torch.tensor([[1, 2], [3, 4]]))   # 使用指定数值
print(torch.randn(2, 3))               # 从标准正态分布采样
print(torch.arange(3, dtype=torch.float32))
```

`dtype` 表示数据类型，`float32` 是常用的浮点类型，可以保存小数。后面需要对参数求梯度时，通常使用浮点张量。

### 运算与广播

形状相同的张量，常见算术运算会在对应位置进行：

```python
a = torch.tensor([1.0, 2.0, 4.0])
b = torch.tensor([2.0, 2.0, 2.0])

print(a + b)    # [3, 4, 6]
print(a * b)    # [2, 4, 8]，对应位置相乘
print(a ** 2)   # [1, 4, 16]，** 表示乘方
print(a.sum())  # 7，把所有元素加起来
print(a == b)   # [False, True, False]，逐个比较是否相等
```

减法、除法同理。Python 中 `=` 用于赋值，`==` 用于判断是否相等。`torch.exp(a)` 则把每个元素 x 变成 eˣ，e 约为 2.718，后面 softmax 会用到。

形状不同，有时也能计算，这叫**广播**。比如一张表加 10，就是每个位置都加 10。

```python
a = torch.tensor([[0], [1], [2]])  # (3, 1)
b = torch.tensor([[0, 1]])         # (1, 2)
print(a + b)
# [[0, 1],
#  [1, 2],
#  [2, 3]]
```

上面相当于把 a 延伸到两列，把 b 延伸到三行，再逐个相加。广播规则是：**从最右边的轴开始对齐，对应长度相等，或者其中一个为 1；缺少的前置轴按 1 处理。** 因此 `(3, 1)` 和 `(1, 2)` 能得到 `(3, 2)`，而 `(2, 3)` 和 `(2,)` 不能直接相加。

### 索引、切片与拼接

Python 从 0 开始编号。索引取某个位置，切片取一段；切片末尾的位置不包含在内。

```python
X = torch.arange(12).reshape(3, 4)
print(X[0])        # 第一行
print(X[-1])       # 最后一行
print(X[1, 2])     # 第二行第三列，值为 6
print(X[0:2, :])   # 前两行、所有列

X[1, 2] = 99       # 修改一个元素
X[0:2, :] = 0      # 把前两行改为 0

A = torch.ones((2, 3))
B = torch.zeros((2, 3))
print(torch.cat((A, B), dim=0).shape)  # (4, 3)，上下拼接
print(torch.cat((A, B), dim=1).shape)  # (2, 6)，左右拼接
```

`dim` 指操作哪个轴。对于这里的二维表，0 是行轴，1 是列轴。拼接时，其他轴的长度必须对应一致。

### 修改原对象与转换类型

`Y = Y + X` 会先算出新结果，再让名字 Y 指向它；`Y += X` 则原地修改 Y。如果另一个变量也指向旧 Y，这两种写法的影响就不同。

`reshape` 有时与原张量共享底层数据，需要独立副本时使用 `clone()`。刚开始不必刻意追求原地操作，尤其在自动求导中，它可能覆盖反向计算需要的数据。

CPU 上不需要求梯度的张量，可以用 `X.numpy()` 转成 NumPy 数组；`torch.tensor(array)` 可以从数组创建张量。只有一个元素时，`x.item()` 能取出普通 Python 数字。普通数字不能继续保留原来的张量求导路径。

## 02.02 数据预处理

实际数据常存在 CSV 表格里，既有数字，也有文字和缺失项。通常先用 pandas 整理，再转成张量。

书里的例子是一张房价表。这里直接创建同样的数据，避免运行前还要准备文件：

```python
import pandas as pd
import torch

data = pd.DataFrame({
    "NumRooms": [None, 2, 4, None],
    "Alley": ["Pave", None, None, None],
    "Price": [127500, 106000, 178100, 140000],
})
# 读取实际 CSV 文件时：data = pd.read_csv("house_tiny.csv")

inputs = data.iloc[:, 0:2].copy()
outputs = data.iloc[:, 2].copy()

inputs["NumRooms"] = inputs["NumRooms"].fillna(inputs["NumRooms"].mean())
inputs = pd.get_dummies(inputs, columns=["Alley"], dummy_na=True, dtype=float)

X = torch.tensor(inputs.to_numpy(dtype="float32"))
y = torch.tensor(outputs.to_numpy(dtype="float32"))
print(X)
print(y)
```

`NumRooms` 是房间数，`Alley` 是巷子类型，`Price` 是房价。前两列是输入特征，最后一列是标签。`iloc` 按行列的位置取数据，`[:, 0:2]` 表示所有行、前两列。

缺失值在 pandas 中通常显示为 `NaN`。这里已知房间数为 2 和 4，均值是 3，因此用 `fillna(...)` 把缺失房间数补成 3。“不知道有几间”不能直接当成“0 间”。均值填补只是一种处理办法，整列都缺失时也算不出有效均值。

巷子类型是文字，使用 `get_dummies` 做独热编码。`Pave` 被写成 `[1, 0]`，缺失被写成 `[0, 1]`；`dummy_na=True` 就是给缺失单独留一列。

最终 X 的形状是 `(4, 3)`：4 套房，每套房有房间数和两个巷子状态。y 中保存四套房的真实价格。到这里完成的是数据整理，还没有训练模型。

实际划分训练集、验证集和测试集后，填补用的均值要从训练集计算，再应用到另外两份数据。类别编码也要保持相同的列，否则输入的含义会变。

## 02.03 线性代数

标量是一个数，向量是一组数，矩阵是一张数表。例如一套房的面积、房间数可以组成向量，多套房的特征排在一起就是矩阵。

常见写法中，xᵢ 表示向量的第 i 个分量，Aᵢⱼ 表示矩阵第 i 行、第 j 列的元素，Aᵀ 表示转置。转置就是让行和列交换位置，`(2, 3)` 的矩阵会变成 `(3, 2)`。

### 求和与轴

```python
import torch

A = torch.arange(6, dtype=torch.float32).reshape(2, 3)
print(A)                         # [[0, 1, 2], [3, 4, 5]]
print(A.T)                       # [[0, 3], [1, 4], [2, 5]]
print(A.sum())                   # 15
print(A.sum(dim=0))              # [3, 5, 7]，把两行合并
print(A.sum(dim=1))              # [3, 12]，把每行的三列合并
print(A.mean())                  # 2.5
print(A.sum(dim=1, keepdim=True)) # [[3], [12]]，保留被汇总的轴
```

`dim=0` 容易和“按行算”混淆。更直接的理解是：指定的轴被汇总掉。A 有两行三列，汇总行轴后，剩下每列的合计；汇总列轴后，剩下每行的合计。

`keepdim=True` 会把这个轴保留为长度 1，后面需要广播时很方便。

### 点积与矩阵乘法

点积是两个等长向量的对应元素相乘，再全部加起来。例如 `[1, 2, 3]` 和 `[4, 5, 6]` 的点积为 `1×4 + 2×5 + 3×6 = 32`。

矩阵乘向量，就是矩阵的每一行分别和向量做点积。若每行是一套房的特征，向量里是各个特征的权重，这一步就能同时算出多套房的加权结果。

```python
a = torch.tensor([1.0, 2.0, 3.0])
b = torch.tensor([4.0, 5.0, 6.0])
print(torch.dot(a, b))  # 32
print(A @ a)           # [8, 26]

B = torch.tensor([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])
print(A @ B)           # [[2, 3], [8, 9]]
```

`@` 是矩阵乘法，和对应位置相乘的 `*` 不同。A 的每一行与 B 的每一列做点积，得到结果中对应位置的数。

因此 `(m, n) @ (n, k)` 得到 `(m, k)`：前一个矩阵的列数，要等于后一个矩阵的行数。矩阵乘法通常也不能随意交换前后顺序。

### 范数

范数用一个数描述向量的大小。常见的 L₁ 范数是各元素绝对值之和，L₂ 范数是平方和再开根号：

```text
x = [3, 4]
L₁ 范数 = |3| + |4| = 7
L₂ 范数 = √(3² + 4²) = 5
```

矩阵的 Frobenius 范数也是把所有元素平方、求和、开根号。后面的权重衰减会用参数的范数构造惩罚项。

## 02.04 微积分

训练需要知道参数怎样调整才能减小损失。导数提供的就是参数变化时，结果会怎样变化的信息。

### 导数

对于 `f(x)=x²`，x 从 2 增加到 2.01，函数值从 4 增加到 4.0401。函数值变化与 x 变化的比值为 `0.0401/0.01=4.01`。

把变化量继续缩小，这个比值会趋近 4，这就是 x=2 处的导数。写成公式是：

```text
f′(x) = lim [f(x+h) − f(x)] / h，h 趋近于 0
```

`f′(x)` 也可写成 `dy/dx`，表示 y 对 x 的导数。对于 x²，导数是 2x，因此在 x=2 时为 4。它描述当前位置的变化率：x 增加很小的一点，输出大约增加它的 4 倍。走得远了，这个比例也会变化。

导数为正时，局部增大 x 会让函数值增大；导数为负则相反。导数为 0 还不能直接认定找到最小值，例如 x² 和 −x² 在 0 处的导数都是 0，但一个是最低点，一个是最高点。

| 函数 | 导数 |
|---|---|
| 常数 c | 0 |
| xⁿ | n×xⁿ⁻¹，先用于正整数次幂 |
| eˣ | eˣ |
| ln(x)，x>0 | 1/x |

`ln` 是自然对数，与 e 的指数运算互为逆运算。求导时，常数倍可以保留，相加的各项分别求导；乘积的导数为 `f′g+fg′`，商的导数为 `(f′g−fg′)/g²`，后者要求 g≠0。

### 偏导数、梯度与参数更新

有多个变量时，可以先固定其他变量，只研究一个变量的影响，这叫**偏导数**。

```text
L(w, b) = w² + 3b
∂L/∂w = 2w
∂L/∂b = 3
```

`∂` 是偏导数符号。把各个偏导按参数顺序放在一起，就得到**梯度**：`∇L=[2w, 3]`。例如 w=2、b=1 时，梯度为 `[4, 3]`。

梯度指向函数在当前位置上升最快的方向。为了减小损失，梯度下降沿反方向更新：

```text
新参数 = 旧参数 − 学习率 × 梯度
```

例如 `L(w)=(w−3)²`，导数为 `2(w−3)`。从 w=0 开始，学习率取 0.1，则新 w 为 `0−0.1×(−6)=0.6`，损失也从 9 降到 5.76。

学习率过大可能越过较好的位置，甚至让损失增大。梯度提供的是局部信息，复杂模型不保证靠它就能找到全局最优。

### 链式法则

如果计算分成 `u=2x`、`y=u²` 两步，x 先影响 u，u 再影响 y。两段变化率相乘，就得到总的变化率：

```text
dy/dx = (dy/du) × (du/dx) = 2u × 2
```

x=3 时，u=6，所以导数是 `12×2=24`。直接对 `y=4x²` 求导也得到同样结果。

神经网络是多层计算，反向传播就用链式法则，从损失开始逐步计算前面各个参数的梯度。如果有多条路径影响结果，各条路径的贡献要相加。

微积分也包括研究累积量的积分，但这里为模型训练准备的重点是微分。减小训练损失属于优化问题，新数据上的表现则属于泛化问题。

## 02.05 自动微分

神经网络参数很多，逐个手算梯度不现实。PyTorch 会记录张量运算的依赖关系，形成**计算图**，然后沿图使用链式法则计算梯度。

```python
import torch

x = torch.arange(4.0, requires_grad=True)
y = 2 * torch.dot(x, x)
y.backward()
print(x.grad)  # [0, 4, 8, 12]
```

这里 `y=2(x₁²+x₂²+x₃²+x₄²)`，对每个 xᵢ 求导得到 4xᵢ，所以梯度为 `[0, 4, 8, 12]`。

`requires_grad=True` 开启梯度跟踪，`backward()` 执行反向传播，结果保存在这里创建的 x 的 `.grad` 中。还没反向计算时，`x.grad` 通常是 `None`；一般中间结果的 `.grad` 默认不会保留。

### 梯度会累加

继续计算一个新函数：

```python
x.grad.zero_()  # 已经有梯度时，把旧值清零
y = x.sum()
y.backward()
print(x.grad)   # [1, 1, 1, 1]
```

如果没有清零，这次的梯度会加到上次结果上。普通训练循环中通常使用 `optimizer.zero_grad()` 清理优化器所管理参数的梯度。

当 y 本身有多个元素时，可以先求和或平均，再反向传播。例如 `y=x*x` 后，使用 `y.sum().backward()`；它等价于 `y.backward(torch.ones_like(y))`。求和与求平均会得到不同尺度的梯度。

### detach 会断开路径

```python
x = torch.tensor(2.0, requires_grad=True)
y = x * x
u = y.detach()
z = u * x
z.backward()
print(x.grad)  # 4
```

虽然 z 的数值是 8，但反向计算把 u 当作不随 x 变化的常数 4，因此相当于对 `4*x` 求导，结果为 4。若直接计算 `z=x*x*x`，梯度则是 `3x²=12`。

`detach()` 保留数值、断开求导路径，通常仍与原张量共享存储。需要独立副本时可以用 `detach().clone()`。

### 算梯度与更新参数

`backward()` 负责计算梯度，更新参数还要交给优化器：

```python
w = torch.tensor(0.0, requires_grad=True)
optimizer = torch.optim.SGD([w], lr=0.1)

optimizer.zero_grad()
loss = (w - 3) ** 2
loss.backward()
optimizer.step()
print(w.item())  # 约 0.6
```

`SGD` 是一种优化算法，`[w]` 指定它管理的参数，`lr` 是学习率。重复训练时，要用更新后的参数重新计算损失，通常每轮都会建立新的计算图。

PyTorch 也能处理带 `if`、`while` 的程序，记录的是本次实际执行的张量运算。但转成普通 Python 数字、NumPy 运算或使用 `detach()`，都可能切断需要的求导路径。

## 02.06 概率

### 概率、分布与采样

用 X 表示一次掷骰子的点数，X 就是随机变量。公平六面骰子满足 `P(X=3)=1/6`，这里 P 表示概率。

一次实验的所有可能结果组成**样本空间**，例如 `{1,2,3,4,5,6}`；“掷出奇数”是一个事件，对应 `{1,3,5}`，概率为 1/2。

概率在 0 到 1 之间，所有互斥且覆盖全部可能性的结果，其概率之和为 1。**互斥**指同一次实验中不能同时发生，比如掷出 1 和掷出 2。

把各种结果和对应的概率一起描述出来，就得到了**概率分布**。按这个分布随机抽取结果，叫采样。

```python
import torch
from torch.distributions import Multinomial

probs = torch.ones(6) / 6
counts = Multinomial(total_count=1000, probs=probs).sample()
print(counts)         # 六个面各出现多少次，总和为 1000
print(counts / 1000)  # 各面的实验频率
```

概率是分布所描述的规律，频率是实际实验的统计结果。掷 10 次，某一面出现 3 次，并不表示它的真实概率变成了 0.3。独立重复的次数足够多时，频率会趋近概率，但不要求每增加一次实验都更接近。

骰子属于离散分布，可能值可以逐个列出。身高、时间等常用连续分布建模；对有概率密度的连续分布，曲线下面某段区间的面积才是该区间的概率，曲线高度本身不是概率。

### 联合概率、条件概率和贝叶斯定理

假设有下面这 100 条观察记录：

| 情况 | 带伞 | 没带伞 | 合计 |
|---|---|---|---|
| 下雨 | 15 | 5 | 20 |
| 没下雨 | 15 | 65 | 80 |
| 合计 | 30 | 70 | 100 |

把表中的比例当作这个例子的概率分配：

- **联合概率**：下雨且带伞，`P(下雨,带伞)=15/100=0.15`。
- **条件概率**：已知带伞，再问下雨的概率，只在 30 个带伞记录中计算，`P(下雨|带伞)=15/30=0.5`。
- 反过来，`P(带伞|下雨)=15/20=0.75`。条件方向变了，分母对应的人群也变了。

竖线 `|` 表示“在……的条件下”。公式为 `P(A|B)=P(A,B)/P(B)`，要求 P(B)>0。

联合概率又能写成 `P(A,B)=P(B|A)P(A)`。把它代进去，就得到**贝叶斯定理**：

```text
P(A|B) = P(B|A) × P(A) / P(B)
```

例如 `P(下雨|带伞)=0.75×0.2/0.3=0.5`，和直接数人数相同。

如果只关心带伞、不关心下不下雨，就把两行加起来：`P(带伞)=P(下雨,带伞)+P(没下雨,带伞)`。把不关心的变量汇总掉，叫**边际化**。

### 独立与条件独立

两次独立掷骰子，第一次是 6，不会改变第二次掷出 6 的概率。独立时有 `P(A,B)=P(A)P(B)`。

独立与互斥不同：独立关心知道一件事会不会改变另一件事的概率；互斥关心它们能不能同时发生。两次都掷出 6 可以同时成立。

条件独立是在某个条件固定以后，变量之间独立。例如可能假设“已知是否患病后，两次检测结果相互独立”。能否这样假设，要根据检测方式判断。

书中的检测例子很能说明条件方向的重要性：假设患病率为 0.15%，患病者全部测为阳性，未患病者有 1% 误报。20 万人中有 300 名患者，另有 1997 名未患病者被误报，所以：

```text
P(患病|阳性) = 300 / (300+1997) ≈ 13.06%
```

误报率只有 1%，阳性结果里却有很多误报，原因是未患病的人群基数大。“患病时能不能测出来”和“阳性以后多大概率患病”，是两个不同的问题。

原文再加入检出率 98%、误报率 3% 的第二次检测，并假设两次检测在患病状态给定后独立，那么两次都阳性时：

```text
P(患病|两次阳性)
= (0.0015×1×0.98) / (0.0015×1×0.98 + 0.9985×0.01×0.03)
≈ 83.07%
```

### 期望、方差与标准差

**期望**是按照概率计算的加权平均。公平骰子的期望为 `E[X]=(1+2+3+4+5+6)/6=3.5`。它描述平均水平，一次实验不一定能取到这个值。

**方差**描述围绕平均值的波动大小：

```text
Var[X] = E[(X−E[X])²] = E[X²] − (E[X])²
标准差 = √Var[X]
```

比如每次都得到 2，方差为 0；一半概率得到 0、一半得到 4，期望同样是 2，但方差为 `(0−2)²×0.5+(4−2)²×0.5=4`，标准差为 2。

`E[X²]` 是先平方再取期望，`(E[X])²` 是先取期望再平方，通常不同。

前面 `torch.randn(...)` 使用的是标准正态分布，分布的均值为 0、标准差为 1。它呈中间高、两侧低的钟形，但实际抽出一小批数字，均值和标准差不必恰好等于 0 和 1。

## 02.07 查阅文档

函数名、参数和返回值不必全靠记忆。`dir` 查看模块提供什么，`help` 查看具体函数怎么用：

```python
import torch

print(dir(torch.distributions))
help(torch.ones)
```

函数说明中常见的 `size` 或 `shape` 是形状，`dim` 是操作轴，`dtype` 是数据类型，`device` 是设备，`requires_grad` 控制是否需要跟踪梯度。

例如不确定 `dim=0` 会得到什么，就拿一个 2×3 矩阵运行，再看结果和形状。这比只看参数名称更容易确认自己的理解。

官方文档：[PyTorch](https://pytorch.org/docs/stable/)、[pandas](https://pandas.pydata.org/docs/)。在 Jupyter Notebook 中，还可以用 `torch.ones?` 查看帮助；这是 Notebook 的用法，普通 Python 文件中使用 `help(torch.ones)`。
