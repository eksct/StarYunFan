与 Softmax 回归的简洁实现（3.7 节）相比，这里的模型总共有两个全连接层：第一层是包含 256 个隐藏单元的隐藏层，随后使用 ReLU 激活；第二层是输出 10 个类别得分的输出层。相比之前只有一个输出层的模型，这里增加了一个带激活函数的隐藏层。

以下代码对照教材的 PyTorch 版本整理，各代码块在安装了 PyTorch、torchvision 和 d2l 的 Notebook 环境中按顺序执行。

## 导入模块

```python
import torch
from torch import nn
from d2l import torch as d2l
```

## 模型定义（PyTorch 版）

```python
net = nn.Sequential(
    nn.Flatten(),         # 把每张 28×28 图片展开为 784 维向量
    nn.Linear(784, 256),   # 隐藏层：784 维输入映射到 256 维
    nn.ReLU(),            # 非线性激活：正数保留，否则输出 0
    nn.Linear(256, 10),    # 输出层：得到 10 个类别得分
)
```

输出层后不额外添加 Softmax，后面的交叉熵损失函数直接接收类别得分。

## 权重初始化

`init_weights` 检查传入的模块：如果是 `nn.Linear`，就把它的权重初始化为均值 0、标准差 0.01 的正态随机数。这里按教材只重新初始化权重，偏置保留 `nn.Linear` 创建时的默认初始化。

```python
def init_weights(m):
    if type(m) == nn.Linear:
        nn.init.normal_(m.weight, std=0.01)


net.apply(init_weights)
```

`net.apply(init_weights)` 会遍历模型及其子模块，两个全连接层的权重都会按上面的规则初始化。

## 加载数据并训练

批次大小为 256，学习率为 0.1，训练 10 轮。与从零实现一样，使用 `reduction='none'` 保留各样本损失，交给 `d2l.train_ch3` 处理。

这篇重新创建自己的 `trainer`，并传入当前模型的 `net.parameters()`，让优化器更新这个模型的参数。

```python
batch_size, lr, num_epochs = 256, 0.1, 10
loss = nn.CrossEntropyLoss(reduction='none')
trainer = torch.optim.SGD(net.parameters(), lr=lr)

train_iter, test_iter = d2l.load_data_fashion_mnist(batch_size)
d2l.train_ch3(net, train_iter, test_iter, loss, num_epochs, trainer)
```
