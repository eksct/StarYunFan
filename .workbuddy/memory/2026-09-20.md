## 代码块语言自动识别（无标记的 320 处）
- 之前 320 个无语言标记的代码块渲染成纯文本（无高亮）。先试了 `hljs.highlightAuto` 受限子集，但短片段相关性低（json/sql/yaml 都 <8 落回纯文本），且把 java 误标成 typescript——不可用。
- 改为 `src/utils/markdown.ts` 里的 `guessLanguage()`：高精度的签名式正则识别（json 用 JSON.parse 兜底，sql/dockerfile/nginx/bash/ini/properties/java/python/go/yaml/xml/css 各有特征规则），仅在确信时返回语言名，否则返回 '' 保持纯文本，绝不误标。
