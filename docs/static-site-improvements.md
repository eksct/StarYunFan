# 静态站改进清单

本轮实现范围如下。网站继续发布到 GitHub Pages，无服务端运行依赖。

| 项目 | 实现 |
| --- | --- |
| 1. 发布白名单 | Vite 只复制 `.generated-public`；仅收集公开文章引用的附件，不发布原始 Markdown、草稿、隐藏目录或 Obsidian 配置。每次生成清理过期附件。 |
| 2. 统一构建入口 | `build`、`build-only`、直接 `vite build` 均执行同一 Vite 生成流程，校验失败终止构建。 |
| 3. 阅读请求竞态 | 切换文章取消旧请求，并校验请求序号；离开页面取消请求、清理观察器和计时器。支持失败重试。 |
| 4. 集合面包屑 | 集合取文件夹路径，分类独立展示；返回笔记按钮保留原搜索或集合地址。 |
| 5. 双链消歧 | 优先完整路径、相邻路径，其次唯一后缀或唯一标题；歧义和指向未发布文章的链接阻止构建。 |
| 6. 内部链接与锚点 | 支持普通 Markdown 链接、同页标题、跨页标题及 Obsidian 块引用，静态页与站内均可跳转。 |
| 7. Token 转换 | 在 Markdown token 层处理双链、图片和链接，保留图片标题，代码块和行内代码不参与替换。 |
| 8. Frontmatter 校验 | YAML 解析；校验支持字段、类型、日期、重复字段及发布时间顺序；报错标明文章路径。 |
| 9. 统一文章正文 | 构建一次生成 HTML，供独立文章页和站内 JSON 使用；仅去除重复的页面标题，保留真实章节与唯一锚点，页面只显示一个 H1。 |
| 10. 元信息生命周期 | 路由统一更新标题、描述、canonical、OG 及日期；离开文章恢复页面元信息；分享标题响应路由变化。 |
| 11. 主题容错 | 本地存储不可用时可继续切换；未手动选择时跟随系统，跨标签页同步选择。 |
| 12. 搜索质量 | 按相关性全局排序、显示命中片段并高亮；按需获取 JSON 索引，失败后可直接重试。 |
| 13. 浏览状态 | 查询和集合保存在 URL；浏览器返回和文章返回按钮恢复列表位置，等待异步结果后再恢复滚动。 |
| 14. 手机阅读 | 折叠菜单、手机文章大纲；表格和代码区域独立横向滚动，正文列可收缩。 |
| 15. 基础无障碍 | 主内容地标、跳过导航、焦点样式、加载与复制状态播报；弹层 Escape、焦点返回，图片可用键盘打开。 |
| 16. 两种日期 | `publishedAt` 与 `updatedAt` 独立存储、展示；RSS 使用发布日，站点地图使用更新日，结构化数据包含两者。 |
| 17. 配置与 CI | 地址与集合规则集中配置；Node >=22.13，推荐 24；CI 执行 lint、回归测试、类型检查、构建和产物校验。 |
| 18. 性能 | 构建时渲染与高亮，浏览器无需下载 Markdown 解析器；引用图片压缩、尺寸声明、延迟加载；主题变化仅更新背景颜色，复用几何图形。 |

## 日期说明

显式 `publishedAt`（兼容 `date`）优先于 Git 首次提交日；显式 `updatedAt` 优先于 Git 最近提交日。没有 Git 历史的源码包以文件日期作为回退。批量导入笔记的 Git 首次提交日只能反映导入时间，真实写作日期需要在 frontmatter 中填写。

## 验证

- `pnpm test`：发布白名单、过期附件清理、草稿、链接消歧、锚点、代码保护、图片标题、日期及搜索重试等回归。
- `pnpm lint`、`pnpm build`：代码检查、完整生产构建和类型检查。
- `pnpm build-only` 后运行 `node scripts/verify-dist.mjs`：确认直接构建入口也遵守发布白名单；逐篇检查正文一致、单个 H1、本地图片和内部链接。
- 浏览器检查：搜索失败重试、查询与滚动恢复、快速切换文章、元信息恢复、集合导航、块锚点、手机菜单和大纲、图片键盘预览及存储禁用时的主题切换。
