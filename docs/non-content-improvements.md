# 非内容优化统一收口（2026-10-21）

本轮只处理纯静态站的实现、阅读、访问和发布体验。不修改文章正文、标题、日期、标签、个人资料、友链资料、项目案例，也不增设服务端系统。

| 统一范围 | 完成标准 |
| --- | --- |
| 搜索 | 正文、围栏代码及缩进代码均可命中；集合内可搜索；查询保留在 URL；加载失败可重试 |
| 加载容错 | 文章及索引下载和 JSON 解析有 10 秒超时；错误响应、无效数据有反馈；换页取消旧文章请求 |
| 阅读顺序 | 列表与前后导航共用文件名自然排序；前后文章限定同目录；独立页采用同一规则 |
| 文章大纲 | H2–H6 可跳转，桌面、手机及独立页均呈现层级 |
| 主题 | 两种阅读方式均可选择自动、浅色、深色；响应系统变化与其他标签页的设置/清空操作 |
| 打印 | 两种阅读方式均可打印/保存 PDF；白底、隐藏工具、大纲、背景；代码和表格可换行 |
| 静态 404 | GitHub Pages 错误页包含首页及笔记入口；CSS、图标均使用站点基础路径；不参与索引 |
| 阅读层次 | 减弱背景，正文有实色阅读面板；浅色辅助文字增强对比；保持手机可读宽度 |
| 图片交互 | 两种阅读方式采用原生模态对话框；支持键盘、Escape、焦点返回、背景滚动锁定；保留失败图片防护 |
| 更新与发布 | 失效脚本/路由分块有重新加载入口，不自动循环刷新；build/build-only 均执行产物检查 |

顺序以现有目录与文件名为依据，不推断未编号文章的教学关系。后续如需人工编排课程顺序，应另行提供内容顺序。

## 验证记录

- lint、TypeScript、生产构建及自动产物检查通过，19 项 Node 回归测试通过。
- 76 篇文章的站内页和独立页共 152 页通过 320px 宽度检查，无页面横向溢出。
- 7 类路由在浅色/深色、手机宽度下通过布局检查。
- 浏览器验证了代码检索、集合过滤、查询恢复、两种阅读方式的前后导航、H4–H6 大纲、主题同步、系统变化、存储禁用、打印样式、图片模态及焦点返回。
- 故障注入验证了入口脚本/路由分块失效、文章/索引超时后重试、无效数据、换页取消请求。
- 上一轮的图片失败保护、背景滚动恢复、剪贴板取消、编码路径/查询/锚点和首标题保留回归检查通过。
- 发布以源提交标记、GitHub Actions / Pages 结果和线上产物一致性核对作为交付依据。

这份清单是本轮的验收范围，不代表不存在任何未来功能或新环境下的问题。
