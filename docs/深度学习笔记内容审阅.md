## 01 线性回归

对应笔记：[线性回归](../public/postDir/major/深度学习/线性回归.md)。依据：[D2L 线性回归](https://zh-v2.d2l.ai/chapter_linear-networks/linear-regression.html)。

### 01.1 “倒置”在这里指转置 公式没有错

**判断：术语建议，不是知识或计算错误。** 原句：`ŷ = w^T x + b (w的倒置)`。

公式中的 `w^T` 已明确表示转置，括号里的“倒置”可以结合这个符号理解为行列交换。原文没有说要计算逆矩阵，不能仅凭“倒置”这个用词认定作者混淆了转置与求逆。

**术语建议：** 正式的数学名称是“转置”。写成“w 的转置”更便于与教材术语对应，但原句的公式和所表达的转置含义可以保留。

### 01.2 真实答案不是模型的预测

**后续修订：** 本条所述平方误差公式已按要求单独修正为 `l⁽ⁱ⁾(w, b) = ½(ŷ⁽ⁱ⁾ − y⁽ⁱ⁾)²`，同步更新博客副本与原始学习目录中的《线性回归》。下面保留审阅时的原句与解释；这是初次排版完成后的内容修订。

**判断：术语与公式容易误导。** 原句：“预测的结果称为目标”；平方误差中又把真实值写成带有 `w、b` 的 `y`。

监督学习中的目标或标签是数据里已有的真实答案 `y`，模型给出的结果是预测 `ŷ`。通常变化的是预测，标签不会随着模型参数一起变化。

**正确理解：** 一套房的成交价是标签，模型算出的估价是预测。单样本平方损失可以写成 `½(ŷ − y)²`，其中 `ŷ = wᵀx + b`。

### 01.3 全量遍历是在为引出小批量方法作铺垫

**判断：上下文衔接建议，不应判为确定的概念混用。** 原文相邻两句：“每一次更新参数之前，我们必须遍历整个数据集”；“通常会在每次需要计算更新的时候随机抽取一小批样本，这种变体叫做小批量随机梯度下降”。

结合后一句，前一句可以理解为介绍全批量梯度下降的计算开销，随后引出只抽取一小批样本的变体。不能只截取前一句，就认定作者把小批量更新理解成每次必须遍历全部数据。两句之间没有明确的转折，而且都位于“小批量随机梯度下降”标题下，容易让读者暂时误判前一句的适用对象。

**衔接建议：** 可表述为“全批量梯度下降每次更新参数都要使用整个数据集，计算开销较大。为减少单次更新的开销，可以随机抽取一小批样本来估计梯度，这种变体叫做小批量随机梯度下降。”这是将已有上下文连接得更明确，不是纠正已确认的知识错误。本次未据此改写笔记正文。

### 01.4 正规方程中的逆矩阵并不总是存在

**判断：缺少适用条件。** 原句：`w* = (X^T X)⁻¹ X^T y`；后面又说参数“只能是用随机梯度下降一遍一遍算”。

这个逆矩阵公式要求 `XᵀX` 可逆。如果特征重复或线性相关，逆可能不存在；即使存在，实际计算也常用更稳定的最小二乘求解方法。单独的偏置还需要加入全为 1 的特征列，或作相应的数据中心化处理。

**正确理解：** 线性回归可以用最小二乘求解，也可以迭代优化，不是只能用 SGD。无唯一解时可使用伪逆、QR 或 SVD 等方法；这些方法的目的都是处理线性方程，而不是让不存在的逆矩阵强行存在。

### 01.5 SGD 不保证每一步都下降或最终到达全局谷底

**判断：表达过满。** 原句：“SGD会不断向梯度的负方向前进，直到谷底”。

SGD 使用的是小批次对整体梯度的估计，有随机波动。对于一般深度网络，不能承诺每一步都降低整体损失，也不能承诺到达全局最优。

**正确理解：** 它尝试沿着估计的下降方向更新参数；是否稳定收敛还受学习率、数据、初始化和问题本身影响。对满足特定条件的凸问题，可以讨论更严格的收敛结论。

### 01.6 正态噪声假设不是对所有预测误差的事实描述

**判断：缺少条件。** 原句：“噪声即误差，通常一个模型的真实值跟预测值误差很小，很小的概率误差会大”。

观测噪声是数据生成过程中的随机扰动；当前模型的残差还可能包含模型没学好、模型形式不合适等影响。残差不必天然是小的，也不必服从正态分布。

**正确理解：** 在线性关系加独立、零均值、等方差高斯噪声的假设下，最大化似然与最小化平方误差对应。这是选择损失函数的一种推导，不能据此断言实际数据一定满足该假设。

## 02 Softmax 回归

对应笔记：[softmax回归](../public/postDir/major/深度学习/softmax回归.md)。依据：[D2L Softmax 回归](https://zh-v2.d2l.ai/chapter_linear-networks/softmax-regression.html)、[PyTorch CrossEntropyLoss](https://docs.pytorch.org/docs/2.14/generated/torch.nn.CrossEntropyLoss.html)。

### 02.1 教材切换了权重矩阵的排法 笔记需要保留这项说明

**判断：矩阵形状的说明缺失，不能直接判为作者理解错误。** 笔记先给出 `O = Wx + b` 和 `W = 类别数 × 特征数`，又给出批量公式 `O = XW + b`。核对 D2L 原文后可确认：教材自身在两处采用了不同形状的 W，并在批量公式前重新说明了形状。

D2L 的 3.4.2 节用 4 个特征、3 个类别举例，写 `o = Wx + b`，明确 W 是 `3×4`。3.4.5 节改用批量数据，明确 X 是“样本数×特征数”、W 是“特征数×类别数”，再写 `O = XW + b`。因此两处公式可以分别成立，关键是后一个 W 的行列排法已经改变。笔记省略了后一次形状说明，读者容易以为还沿用前一个 W。

**易懂的记法：** “单样本公式里，W 按类别数×特征数排列；批量公式采用教材接下来的约定，将 W 按特征数×类别数排列，所以写 O = XW + b。”如果想始终沿用同一个“类别数×特征数”的 W，批量公式就写 `O = XWᵀ + b`。

**符号补充：** 原文 o、O 表示 Softmax 之前的得分，ŷ、Ŷ 表示 Softmax 之后的预测概率。帽子表示预测值，不改变矩阵的行列数；转置则用上标 T 或 `ᵀ` 表示。这里的形状切换不能通过给 O 加帽子来解决。

### 02.2 类别编号可以作为标签使用

**判断：容易误解。** 原句：“为什么要这样设计，而不是直接用 1、2、3 数字？”随后说数字会让模型误以为类别有大小关系。

把类别编号直接当成连续数值做回归，确实可能引入错误的大小关系。但把编号交给分类损失，让它表示“第几个类别”，不会自动引入这样的大小关系。

**正确理解：** `CrossEntropyLoss` 可以接收类别索引标签，通常无需手动把标签转成独热向量。比如 0 表示猫、1 表示狗、2 表示鸡，损失函数把 1 当成“选择狗的那一列”，不是把狗理解成猫的两倍。

### 02.3 只看真实类别概率需要硬标签条件

**判断：需要补条件。** 原句：“它只关注真实类别对应的那个预测概率”。

这对单标签分类的独热目标成立，损失为真实类别预测概率的负对数。但标签平滑、知识蒸馏和其他软标签任务中，目标分布可能有多个非零分量。

**正确理解：** 一般交叉熵是对各类别的 `−目标概率 × log(预测概率)` 求和。独热标签把这项求和简化成一个类别；它不是交叉熵的唯一形式。

### 02.4 交叉熵不是仅在猜错时付出的费用

**判断：定义不准确。** 原句：“交叉熵的大小表示猜测值在错误情况下需要支付的费用（比特）”。

即使预测类别正确，只要给真实类别的概率不是 1，交叉熵通常仍大于 0。它可理解为按真实分布平均、使用预测分布编码所需的长度；这个解释还取决于对数的底。

**正确理解：** 真实类别概率从 0.6 提高到 0.9，两次都可能判对，但后者损失更小。用以 2 为底的对数时单位是比特；深度学习库通常用自然对数，此时单位是 nat。固定真实分布时，交叉熵等于真实分布的熵加 KL 散度。

## 03 多层感知机

对应笔记：[多层感知机](../public/postDir/major/深度学习/多层感知机.md)。依据：[D2L 多层感知机](https://zh-v2.d2l.ai/chapter_multilayer-perceptrons/mlp.html)。

### 03.1 教材确实用单调性解释线性模型的限制

**判断：原笔记符合教材此处的说明，可保留；以下属于可选补充。** 笔记原句：“它认为输入和输出之间是‘单调’的关系，也就是说，一个特征变大，输出一定会跟着变大（或变小），而且变化的速度是恒定的。”不能只截取“单调”两个字，就认定笔记把线性模型的限制仅仅理解为单调性。

D2L《多层感知机》4.1.1.1 节明确写道：“例如，线性意味着单调假设：任何特征的增大都会导致模型输出的增大（如果对应的权重为正），或者导致模型输出的减小（如果对应的权重为负）。”随后用体温与死亡率的例子说明限制。笔记沿用了这一解释方向。

**可选补充：** 可以加上“其他特征保持不变时”，让一个特征变化的讨论更明确。教材后面还说明，可以把“体温与 37 摄氏度的距离”作为新特征，帮助线性模型处理原始体温对应的非单调关系。这是特征预处理的补充，与前面的单调性说明并不矛盾，也不构成原笔记的知识错误。

### 03.2 不是每个线性层后都必须再加激活函数

**判断：表达过满。** 原句：“必须在每一层的线性变换之后，加一个非线性函数”；“ReLU……不容易出现‘梯度消失’”。

隐藏层通常需要非线性，才能避免连续仿射变换折叠成一个仿射变换，但输出层是否加激活取决于任务。回归输出可以不加；PyTorch 分类损失通常直接接收 logits，也不需要先做 Softmax。

**正确理解：** ReLU 的正半轴导数是 1，减轻了某类饱和问题，但它不保证整网梯度正常。负半轴的导数为 0，可能出现神经元长期不激活；其他权重矩阵也仍会影响梯度大小。

**当前写法的关键：** `trainer = torch.optim.SGD(net.parameters(), lr=lr)` 将优化器与本篇创建的模型关联起来；不能直接沿用另一个模型的优化器。各代码块按顺序执行即可给出本篇的导入、模型定义、初始化、数据加载和训练过程。笔记还注明：初始化函数只重新设置 Linear 的权重，偏置保留该层创建时的默认初始化，与教材代码一致。

## 06 模型选择 欠拟合和过拟合

对应笔记：[模型选择、欠拟合和过拟合](../public/postDir/major/深度学习/模型选择、欠拟合和过拟合.md)。依据：[D2L 对应章节](https://zh-v2.d2l.ai/chapter_multilayer-perceptrons/underfit-overfit.html)。

### 06.1 欠拟合的简短定义来自教材 须结合前文的高误差背景

**判断：这是 D2L 原文的小结，不能归为笔记作者概括错误；结合笔记前文可以保留。** D2L 4.4.5 节逐字写道：“欠拟合是指模型无法继续减少训练误差。过拟合是指训练误差远小于验证误差。”笔记引用了这一小结，而且前面已经记下训练与验证误差都较高的讨论。

这里的关键背景是：模型还没有把训练数据拟合好，训练误差仍然较高。学习率不合适、优化困难等确实可能导致拟合不足，不能因为这些是训练设置问题，就认定它们与欠拟合无关。之前审阅仅列举这些原因，没有说明真正缺少的条件，解释不充分。

**可选补充：** 若把这句话单独拿出来当判断标准，应补上“训练误差仍然较高”。已经拟合得很好、误差已经很低的模型，也可能不再明显降低训练误差；它不会仅仅因为损失进入平台期就变成欠拟合。另一方面，模型尚未拟合充分时，即使训练误差还在下降，也可能暂时处于欠拟合状态。因此重点是“拟合得不够好”，不能只看误差是否继续下降。

**简短记法：** “欠拟合是模型对训练数据也拟合不足，通常表现为训练误差和验证误差都较高；过拟合是模型在训练数据上拟合得很好，但在验证数据上的表现明显较差。”训练设置故障的排查属于判断原因和选择处理方法，不是要求把所有优化原因排除在拟合不足之外。

**术语补充：** 教材 4.4.3 节自身也有把训练与验证误差的差距叫作“泛化误差”的措辞。更严格的常见区分是：泛化误差指新样本上的预期误差，它与训练误差的差称为泛化差距。这属于对教材用词的补充，不能归为笔记作者独有的错误。

### 06.2 过拟合的解释应结合笔记已有的泛化上下文理解

**判断：结合全文，笔记对过拟合的核心理解成立，不应整体列为知识问题；单张照片的例子可作措辞补充。** 笔记先说明目标是发现能推广到新数据的规律，再介绍训练数据拟合程度与总体表现的差异。不能把其中一句抽离这些背景，认定作者只凭训练次数或误差差距作判断。

“训练误差明显低于验证误差时要小心，这表明严重的过拟合”确实来自 D2L 4.4.3 节。笔记紧接着也保留了教材的提醒：“最终，我们通常更关心验证误差，而不是训练误差和验证误差之间的差距。”因此不能指责笔记没有关注验证表现、只看差距大小。

**可选措辞补充：** “一张照片重复训练多次，会导致模型记住这张照片，记住则过拟合”意在说明记忆与泛化的区别。若想避免读者把反复训练本身当作充分条件，可写成：“如果模型反复训练后，只记住了这张照片，而换成没见过的照片就表现很差，就体现了过拟合。”原例的“会导致”也可以改成“可能导致”。本次未据此改写笔记。

不同数据分布、数据增强和 Dropout 评估模式可能影响误差比较，这些属于实践中的扩展排查知识；在笔记当前的教材语境下，未展开这些细节不构成知识错误。此前审阅把这些扩展条件列作本段欠缺，范围过宽。

### 06.3 时间顺序与群组划分属于 K 折交叉验证的扩展实践知识

**判断：笔记对教材本节的概述成立，不属于已发现的内容错误。** D2L 4.4.2.2 节只介绍把数据分成 K 个不重叠子集、轮流使用一个子集验证、最后对结果求平均。本节没有讨论时间序列、按群组划分或任意打乱数据。笔记也没有声称任何类型的数据都可以任意打乱，不能据此给笔记增加这项错误判断。

**扩展阅读：** 实际应用中，同一患者、同一设备或同一个人的相关样本同时进入训练折和验证折，可能让结果过于乐观；有未来预测要求的时间序列任务，还需要避免使用未来信息评估过去。这些是使用交叉验证时进一步需要了解的条件。

遇到这些任务时，可进一步学习按群组划分、时间顺序验证，以及在每折训练数据上拟合标准化、特征选择等步骤。这不要求初学笔记在概述教材本节时就全部展开，本次不作为必须修改项。

## 07 权重衰减

对应笔记：[权重衰减](../public/postDir/major/深度学习/权重衰减.md)。依据：[D2L 权重衰减](https://zh-v2.d2l.ai/chapter_multilayer-perceptrons/weight-decay.html)、[AdamW 论文](https://arxiv.org/abs/1711.05101)。

### 07.1 权重衰减和 L2 正则化不是在所有优化器里都等价

**判断：缺少关键条件。** 原句：“权重衰减通常也被称为 L2 正则化”。

对普通 SGD，在系数定义对应时，把 L2 惩罚加入目标，与按比例收缩权重可以写成等价更新。但自适应优化器会按参数不同地缩放梯度，直接把 L2 项混进梯度，不再普遍等同于独立的权重衰减。

**正确理解：** 学习 SGD 时可以把两者联系起来；使用 Adam、AdamW 时要检查实际更新规则。AdamW 的关键就是把权重衰减与自适应梯度更新分开处理。

### 07.2 权重小只是某种复杂度约束而不是通用判据

**判断：直觉缺少边界。** 原句：“一个模型的权重越小，它就越‘简单’”。

这个直觉适合解释固定特征、固定参数化下的 L2 惩罚。改变输入单位，或者在多层网络中把一层权重放大、下一层相应缩小，可能改变参数范数却不改变整个函数。

**正确理解：** L2 是对参数的一种偏好，不是能独立衡量所有模型复杂度的万能尺。比较前要统一输入尺度；公式用 `λ‖w‖²` 还是 `λ‖w‖²/2` 也要说明，因为其梯度分别是 `2λw` 和 `λw`。

## 08 暂退法 Dropout

对应笔记：[暂退法（Dropout）](../public/postDir/major/深度学习/暂退法（Dropout）.md)。依据：[D2L 暂退法](https://zh-v2.d2l.ai/chapter_multilayer-perceptrons/dropout.html)、[PyTorch Dropout](https://docs.pytorch.org/docs/2.14/generated/torch.nn.Dropout.html)。

### 08.1 被置零的是激活值 不代表相关参数一定不更新

**判断：确定的过度推论。** 原句：“不参与训练，也不参与参数更新”。

标准 Dropout 对某次前向计算的激活值施加随机掩码。被遮住的这条路径，其当前数据损失梯度为零；但同一个参数可能还被其他样本或路径使用，也可能受优化器动量、权重衰减影响。

**正确理解：** 可以说“本次被遮住的激活不通过这条路径贡献梯度”，不能直接说“某一组模型参数这一轮一定不会改变”。

### 08.2 除以保留概率保证的是局部期望

**判断：需要明确保证的对象。** 原句：“训练时，希望还是等于预测时的输出”；示例给出 `[h1, 0, h3, 0, h5]`。

常见的倒置 Dropout 在训练时将保留值除以 `1−p`，保证给定输入时，这一层输出的随机期望等于未丢弃的输入。单次输出并不相等，经过后续非线性层后的整网预测期望也不必相等。

**正确理解：** `p=0.4` 时，完整的倒置 Dropout 示例应把保留值乘以 `1/0.6`。原来的置零示例只说明了掩码步骤，没有包含缩放。推理时调用 `eval()`，标准 Dropout 就不再随机丢弃。

## 09 数值稳定性和模型初始化

对应笔记：[数值稳定性和模型初始化](../public/postDir/major/深度学习/数值稳定性和模型初始化.md)。依据：[D2L 对应章节](https://zh-v2.d2l.ai/chapter_multilayer-perceptrons/numerical-stability-and-init.html)、[PyTorch 初始化说明](https://docs.pytorch.org/docs/2.14/nn.init.html)。

### 09.1 不同矩阵连乘不能只看各自的特征值

**判断：数学解释不准确。** 原句：“矩阵的连乘由它的特征值决定”。

同一矩阵反复相乘时，特征值可以提供重要信息；不同层的矩阵相乘时，方向如何对齐也很重要。矩阵还可能不是方阵，甚至没有通常意义下的特征值。

**正确理解：** 要关心每层对向量放大、缩小的程度以及连乘后的整体效果。奇异值和矩阵范数是更合适的分析工具：可以先把它们理解成“在最容易被放大的方向上，最多能放大多少”。

### 09.2 数值很大不等于已经发生浮点溢出

**判断：确定的数量级错误。** 原句：“如10的26次方，直接导致数值溢出”。

常见 float32 的最大有限数约为 `3.4×10³⁸`，所以 `10²⁶` 本身还没有超过 float32 的范围。它已经非常大，继续运算、平方或换成更小数值范围的数据类型，才可能溢出。

**正确理解：** 梯度爆炸说的是梯度过大，不要求已出现 `inf` 或 `NaN`；溢出则与数据类型和具体运算有关。

### 09.3 ReLU 和 Xavier 都不是任意深度的稳定保证

**判断：表达过满。** 原句：“ReLU在输入为正数时，梯度恒为1，不会‘衰减’信号。因此，它能让梯度在反向传播时保持稳定”；“这样，无论网络有多深……梯度也能保持稳定”。

原文明确限定正输入，这一半的导数描述是正确的。问题在于从它推出整个网络的梯度稳定：负输入处的导数为 0，整个网络还包含权重矩阵的连乘。初始化的方差推导也依赖独立性、分布和激活函数等近似条件。

**正确理解：** 这些方法改善训练的起点和某些传播条件，但不能免除对实际梯度、激活分布和训练曲线的检查。

### 09.4 打破对称性不等于所有参数都必须随机

**判断：需要补条件。** 原句：“必须用随机值来初始化权重”；相同初值时“无论怎么训练，它们永远都学一样的东西”。

当隐藏单元的连接、激活、初值和梯度路径完全对称时，它们确实容易收到相同更新。随机权重是常见的破坏对称方法，但不是数学上唯一的方法；偏置初始化为零通常没有问题。

**正确理解：** 关键是让需要分工的隐藏单元有不同的学习起点或路径，而不是禁止任何零初始化。线性回归也没有多隐藏单元的这种对称性问题。

### 09.5 Kaiming 不是把 Xavier 的方差一律乘以二

**判断：确定的公式关系错误。** 原句：“它在Xavier的基础上把方差再乘以2”；后面又列出 `2/nin` 与 `2/(nin+nout)`。

常见、增益为 1 的 Xavier 方差是 `2/(nin+nout)`。针对 ReLU、采用 fan_in 模式的 Kaiming 方差是 `2/nin`。两者的比值是 `(nin+nout)/nin`，只有输入输出数量相等时才是 2。

**正确理解：** 若输入 100 维、输出 300 维，Xavier 方差为 `0.005`，上述 Kaiming 方差为 `0.02`，相差 4 倍。Kaiming 还可以选 fan_out 或其他激活增益，不能脱离这些选项谈固定倍数。

### 09.6 ReLU 恰好把方差减半的说法不够准确

**判断：推导中的量混用了。** 原句：“ReLU会把一半的输入‘砍掉’……输出方差减半”。

在对称、零均值的输入假设下，ReLU 输出的二阶矩，即“平方后再求平均”，会减半。但 ReLU 输出的均值通常不再是零，方差还要减去均值的平方。

**正确理解：** Kaiming 推导中常跟踪的是二阶矩。不要把“约一半位置变成零”“二阶矩减半”和“方差严格减半”当成同一个结论。

## 10 环境和分布偏移

对应笔记：[环境和分布偏移](../public/postDir/major/深度学习/环境和分布偏移.md)。依据：[D2L 环境和分布偏移](https://zh-v2.d2l.ai/chapter_multilayer-perceptrons/environment.html)。

### 10.1 协变量偏移还要求输入与答案的条件关系不变

**判断：缺少定义中的关键条件。** 原句：“输入变化了，比如说训练是真实世界的猫狗，预测的素材是卡通猫狗”。

协变量偏移不只是输入看起来变了，还假设给定输入时标签的条件分布保持不变。照片变成卡通可能同时改变许多关系，不能仅凭这个例子就确认属于纯协变量偏移。

**正确理解：** 输入分布 `p(x)` 变化、条件关系 `p(y|x)` 不变，才是这里讨论的设定。用重要性权重纠正时，还需要目标域出现的输入在训练域有覆盖；训练中从未见过的区域，不能靠给已有样本加权凭空补出来。

### 10.2 概念偏移不总是换任务 也不总要从零训练

**判断：例子范围过窄且结论过强。** 原句：“同一个词，含义变了”；“除了重新收集数据、重新训练，没有别的办法”。

概念偏移通常指给定同一输入时，答案的条件分布随环境变化。它可以是同一任务的规则慢慢变了，例如某类交易在新环境中更容易构成欺诈，不一定是把猫狗分类改成颜色分类。

**正确理解：** 需要新标签、更新模型、在线适应或重新设计任务，取决于变化的性质。某个任务彻底改变的例子，不能推出所有概念偏移都必须从零训练。

### 10.3 混淆矩阵估计标签比例需要验证集和可解条件

**判断：缺少使用条件，存在评估偏乐观的风险。** 原句：“混淆矩阵本身是在训练集上算出来的”。

若直接拿模型已经拟合过的训练样本估计分类错误，容易把混淆矩阵估得过于理想。通常应使用来自源分布、未用于拟合模型的带标签验证数据。

**正确理解：** 把矩阵每列定义成“某个真实类别会被预测成各类别的概率”。若只发生标签比例变化、各类的输入分布保持不变，就可写“目标域预测比例 = 混淆矩阵 × 目标域真实类别比例”。还要能稳定求解这个关系；分类器无法区分类别、矩阵接近不可逆时，估计可能很不稳定。用验证集不代表估计一定精确。

## 11 深度学习计算

对应笔记：[深度学习计算](../public/postDir/major/深度学习/深度学习计算.md)。依据：[D2L 模型构造](https://zh-v2.d2l.ai/chapter_deep-learning-computation/model-construction.html)、[PyTorch Module](https://docs.pytorch.org/docs/2.14/generated/torch.nn.Module.html)、[PyTorch 自动求导说明](https://docs.pytorch.org/docs/2.14/notes/autograd.html)。

### 11.1 层不一定有可学习参数 自动求导也不由 Module 单独提供

**判断：定义需要收紧。** 原句：“层……并拥有一组可调整的参数”；把“能自动求导”列为 `nn.Module` 的能力。

ReLU、池化或笔记自己的 `CenteredLayer` 都可以没有可学习参数。PyTorch 自动求导由张量运算及其计算图机制承担；使用 `nn.Module` 的主要价值是组织计算、注册参数和子模块，并统一管理状态。

**正确理解：** 有 `nn.Module` 不意味着任何写进去的运算都会保留梯度。反过来，不继承它，也能用张量运算和 autograd 写训练程序，只是失去了许多模块化管理的便利。

### 11.2 Sequential 可以装入内部带残差的模块

**判断：表达过满。** 原句：“nn.Sequential 做不了跳跃连接……所以你才需要继承 nn.Module”。

`Sequential` 本身按顺序连接子模块，不提供“取前面某个输出再相加”的通用编排语法。但一个子模块可以在内部完成残差连接，再把它放进 `Sequential`。

**正确理解：** “Sequential 不能直接用列表表达任意连接图”是准确的；“用了 Sequential 的网络就不能有跳跃连接”则不准确。

### 11.3 退化问题不能简单等同于梯度消失

**判断：原因解释过度简化。** 原句：“它的根源在于……梯度在反向传播时逐层衰减”。

退化现象是更深的普通网络训练误差反而更高。它说明优化困难，但不能只用梯度消失解释全部现象。ResNet 原论文是在已有初始化和归一化手段缓解梯度问题的背景下，继续讨论加深后的优化困难。

**正确理解：** 残差参数化让模型更容易表达“保留输入并作必要调整”，提供较直接的信号和梯度路径。它的价值比“只解决梯度太小”更广。

### 11.4 残差结构不保证加层后永远不会变差

**判断：确定的无条件保证错误。** 原句：“最坏情况也就是‘什么也没学到’，不会让网络变差”。

结构允许某种恒等映射，不等于优化器一定找到它，更不等于新增结构没有过拟合、数值或计算代价。带有投影、归一化、激活的具体残差块，也要看它如何实现恒等路径。

**正确理解：** 残差网络让训练更深的模型成为可行方案，但模型是否更好仍要验证。原论文中很深的 CIFAR 网络也会面对泛化问题，不能把“更容易优化”读成“性能永不下降”。

### 11.5 Inception 的时间早于 ResNet

**判断：历史关系不准确。** 原句：“无论是 DenseNet、Inception、还是后来的 Transformer，都……借鉴了残差连接的思想”。

最初的 GoogLeNet/Inception 出现在 2014 年，ResNet 论文是 2015 年。后来的 Inception-ResNet 确实结合了两者，但不能把原始 Inception 说成 ResNet 的后继。

**正确理解：** DenseNet 的稠密拼接、原始 Inception 的多分支计算、ResNet 的相加连接，是需要分开理解的结构。它们有联系，连接方式和历史顺序却不同。可对照 [GoogLeNet 论文](https://arxiv.org/abs/1409.4842) 与 [ResNet 论文](https://arxiv.org/abs/1512.03385)。

### 11.6 state_dict 不只包含 float32 参数

**判断：确定的范围与类型错误。** 原句：“state_dict()……每个参数都存储为 float32”。

`state_dict()` 通常包含参数和持久 buffer；浮点参数可以是 float32、float16、bfloat16、float64 等，某些 buffer 还是整数。它描述的是当前状态，不会强制把它们统一转换成 float32。

**正确理解：** 看实际张量的 `dtype`。读取参数数值不必使用 `.data`；打印张量即可查看，若想拿一个不跟踪梯度的视图，通常用 `detach()`。

### 11.7 MyLinear 的前向计算把权重从计算图中分离了

**判断：会影响训练的确定问题。** 原句：`linear = torch.matmul(X, self.weight.data) + self.bias.data`。

`.data` 绕开了这些参数原本的梯度追踪。即使 `self.weight` 与 `self.bias` 被注册为 Parameter，这个表达式也没有沿着正常的参数计算路径建立图，因此它们无法按预期从该损失获得梯度。

**正确理解：** 前向运算应直接使用参数对象。下面是修正示意，未替换原笔记：

```python
def forward(self, X):
    linear = X @ self.weight + self.bias
    return F.relu(linear)
```

注册参数只是让模型和优化器能找到它；它还需要真的参与损失的可求导计算，并交给优化器更新。

### 11.8 注册为 buffer 不会自动取消张量求梯度

**判断：确定的机制误解。** 原句：“register_buffer 注册的张量：不参与梯度计算”。

普通 buffer 常由默认不求梯度的张量创建，但“是否求梯度”和“是否注册为 Parameter”是不同的机制。注册为 buffer 不会自动把一个已有张量的 `requires_grad` 改成 False。

**正确理解：** buffer 不会出现在 `model.parameters()` 中，通常不交给优化器；它会随模型迁移设备。默认持久 buffer 进入 `state_dict()`，但 `persistent=False` 的 buffer 不进入该字典。是否参与计算图，仍取决于张量和实际运算。

### 11.9 有几处文本不能直接作为 Python 执行

**判断：确定的语法或名称问题。** 原句包括 `)这也是块`、代码前单独的 `python`、`requires_grad = false` 和小写的 `nn.module`。

中文说明要放到注释或代码块外；Python 布尔值是 `False`，不是 `false`；模块基类是大小写准确的 `nn.Module`。单独的 `python` 不是语言声明，在程序里会被当成名称。

**正确理解：** 排版后这些片段更容易定位，但本次保留了这些原始字符，不能把“有语法高亮”误认为“已修成可运行代码”。

## 12 卷积神经网络

对应笔记：[卷积神经网络](../public/postDir/major/深度学习/卷积神经网络.md)。依据：[D2L 从全连接层到卷积](https://zh-v2.d2l.ai/chapter_convolutional-neural-networks/why-conv.html)、[PyTorch Conv2d](https://docs.pytorch.org/docs/2.14/generated/torch.nn.Conv2d.html)、[PyTorch MaxPool2d](https://docs.pytorch.org/docs/2.14/generated/torch.nn.MaxPool2d.html)。

### 12.1 卷积的平移等变不等于整个网络平移不变

**判断：核心概念需要区分。** 原句将“平移不变性”列为图像特性，并据此解释卷积。

忽略边界、采用适当步幅等条件时，输入平移，卷积产生的特征图也跟着平移，称为等变。不变则是输入平移后最终结果不变，它不是一般卷积层自动保证的性质。

**正确理解：** 同一个检测器可以在不同位置识别相似模式，是共享卷积核的直觉；池化、聚合和训练可能让分类结果对位置不敏感。步幅和填充还可能破坏简单的平移对应关系。

### 12.2 共享的是卷积权重 不是图片本身的参数

**判断：术语容易造成错误图景。** 原句：“复用图片参数(参数共享)”；“卷积层有两个需要训练的参数”。

输入图片是数据；可学习的是卷积核等模型参数。“权重和偏置”是两类参数张量，不是只有两个可学习数值。偏置也可以通过配置关闭。

**正确理解：** 同一组卷积权重在多个空间位置使用。普通、非分组卷积的权重形状为 `C_out × C_in × K_h × K_w`，其元素数量通常远不止两个。

### 12.3 池化步幅没有不能大于窗口的普遍限制

**判断：确定的限制条件错误。** 原句：“池化窗口的步幅……反正不会大于自身”。

许多接口允许步幅大于窗口，只是这样可能跳过部分位置。步幅等于窗口大小是常见的不重叠配置，不是必须遵守的数学规则。

**正确理解：** 例如宽为 2 的池化窗口可以每次移动 3 格；它会留下未覆盖区域，是否合适要看目的。输出尺寸还受填充、取整方式等设置影响。

### 12.4 输出尺寸公式是一个特例 要说明 padding 的含义

**判断：需要补条件，原特例并非本身算错。** 原句：`n - k + p + 1`，并明确说 p 是 padding 总量。

当步幅为 1、膨胀率为 1，且 p 表示该轴两侧填充之和时，这个式子是对的。PyTorch 的 `padding=1` 通常表示每侧填 1，合计是 2，不能直接把接口里的 1 代入笔记的总量 p。

**正确理解：** 对称填充时的一般单轴公式是 `floor((n + 2p − d(k−1) − 1)/s + 1)`。这里 p 是每侧填充，s 是步幅，d 是膨胀率。最常见的 `k=3、p=1、s=1、d=1` 才得到输出尺寸与输入相同。

### 12.5 卷积核数量和参数数量混在了一起

**判断：数量含义不清。** 原句：“卷积核的数量：输入 x 输出 x 卷积核大小”；“1x1……空间尺寸不变”。

普通卷积中，每个输出通道对应一组跨越所有输入通道的滤波权重。若说输出滤波器数量，通常是 `C_out`；若说权重元素数量，则是 `C_out×C_in×K_h×K_w`，另有可选偏置。分组卷积还要考虑 groups。

**正确理解：** 输入 3 通道、输出 16 通道、3×3 的普通卷积，权重元素数为 `16×3×3×3=432`。1×1 卷积是否保持空间大小仍取决于步幅和填充；步幅为 2 时同样可以下采样。

### 12.6 池化没有可学习权重 不等于不参与训练

**判断：表述需要修正。** 原句：“池化层并没有起到训练的作用”。

最大池化通常没有可学习的权重，但参与前向计算，也会把梯度传给选中的输入位置。平均池化则会把梯度按其规则分配给窗口中的输入。

**正确理解：** 不更新自己的参数，与不影响训练，是两件事。池化会影响特征、梯度传播和模型最终能学到什么。

### 12.7 Conv2d 示例用了非 Python 的注释

**判断：确定的语法问题。** 原句在 `nn.Conv2d(...)` 的参数后写 `//输入`、`//输出通道128` 等。

这与前面 MLP 的问题相同：Python 的行尾注释需要 `#`。原样的 `//` 会被解释为整除运算的一部分，而不是说明文字。

**正确理解：** 调整格式只能让示例更好读，不能把这些字符自动变成合法注释；需要运行时再按审阅意见修正。

## 13 现代卷积神经网络

对应笔记：[现代卷积神经网络](../public/postDir/major/深度学习/现代卷积神经网络.md)。依据：[D2L AlexNet](https://zh-v2.d2l.ai/chapter_convolutional-modern/alexnet.html)、[D2L NiN](https://zh-v2.d2l.ai/chapter_convolutional-modern/nin.html)、[D2L GoogLeNet](https://zh-v2.d2l.ai/chapter_convolutional-modern/googlenet.html)、[D2L DenseNet](https://zh-v2.d2l.ai/chapter_convolutional-modern/densenet.html)、[PyTorch BatchNorm2d](https://docs.pytorch.org/docs/2.14/generated/torch.nn.BatchNorm2d.html)。

### 13.1 AlexNet 推广了 ReLU 不是发明了 ReLU

**判断：历史表述不准确。** 原句：“AlexNet提出了创新的ReLu激活函数”；“Sigmoid……深层网络根本无法训练”。

ReLU 在 AlexNet 之前已有相关研究和使用，AlexNet 展示了它在大规模视觉网络上的训练优势。“Sigmoid 容易饱和、训练困难”也不等于一切带 Sigmoid 的深层模型都根本不能训练。

**正确理解：** 可以把 AlexNet 的贡献记为大规模使用非饱和激活、数据增强和 GPU 训练等组合取得突破。可参考 [Nair 与 Hinton 2010 年论文记录](https://icml.cc/Conferences/2010/papers/432.pdf)。

### 13.2 裁剪尺寸要区分原论文和复现版本

**判断：版本混用。** 原句：“原文……227×227 的裁剪区域”。

AlexNet 原论文描述 224×224，227×227 常见于复现或特定首层尺寸约定；所引用 D2L 示例也使用 224×224 的输入。首层是否填充、步幅和后续展平尺寸必须一起看。

**正确理解：** 不能单独背一个尺寸并声称所有 AlexNet 实现都一致。复现时用代码逐层计算输出形状；不同实现得到的最后特征图大小，可能改变第一层全连接层的参数量。

### 13.3 两个全连接层的参数本身不是将近 1 GB

**判断：确定的数量级问题。** 原句：“这两个巨大的全连接层拥有将近1GB的模型参数”。

用常见的最后特征图 `256×6×6` 计算，第一层全连接权重为 `9216×4096`，第二层为 `4096×4096`，合计约 5453 万个数。以 float32 的每个数 4 字节计，权重约 218 MB，另加很少量偏置。

**正确理解：** 参数存储、梯度、优化器状态、激活和临时空间是不同的显存项目。完整训练可能占用远多于 218 MB，但不能把总训练显存说成这两个层的参数大小。

### 13.4 VGG 的每个块不一定都把通道翻倍

**判断：架构特例被写成通则。** 原句：“下一个块的输出通道数就翻一倍”。

常见 VGG 通道序列是 `64→128→256→512→512`，最后两个块并没有再次翻倍。

**正确理解：** “空间分辨率逐步降低，通道通常逐步增多”是结构直觉；具体每个块用多少通道由配置决定。

### 13.5 NiN 的非线性不能只归因于 1×1 卷积

**判断：缺少关键组成。** 原句：“用‘1×1卷积’增强了卷积层的非线性表达能力”。

1×1 卷积本身在每个空间位置执行通道间的仿射变换。如果不夹入非线性激活，连续的这些变换仍可合并成一个仿射变换。

**正确理解：** NiN 的微型 MLP 由卷积与激活一起形成。真正的非线性来自 ReLU 等激活，1×1 卷积负责可学习的通道组合与变换。

### 13.6 GoogLeNet 同时使用深度和多分支结构

**判断：概括有矛盾。** 原句：“靠堆深度，而是靠‘拓宽’和‘并行’来变强。而不是堆深度”。

GoogLeNet 并不是排斥深度；它也堆叠多个 Inception 块，利用瓶颈降维和多尺度并行控制计算量。

**正确理解：** 它把“变深”和“在块内部做多分支计算”结合起来，不能只记成拓宽。各分支拼接需要高宽一致，并不要求不同分支的输出通道数一样多。

### 13.7 BatchNorm 除以尺度 不会把每层最终输出锁死为标准分布

**判断：一处确定笔误，多处缺少条件。** 原句：“减标准差是尺度调整”；“将每层的输出重新拉回标准输入”；公式没有显示 ε。

尺度调整是除以标准差相关的量，不是减去标准差。实际常见公式为 `γ × (x−均值)/sqrt(方差+ε) + β`；小正数 ε 用于避免除零等数值问题。之后的可学习 γ、β 又能改变均值和尺度。

**正确理解：** BN 不是必须放在每层的自动规则，也不保证防止过拟合。用批次统计量是训练时的常见行为；默认推理使用运行统计量，但 PyTorch 设 `track_running_stats=False` 时，推理仍使用当前批次统计量。

### 13.8 DenseNet 的直接密集连接主要在同一个稠密块内

**判断：范围与数量描述不准确。** 原句：“所有层看到前面的原始输出”；“每个稠密块内部的层数逐渐增加（例如6层、12层、24层、16层）”。

稠密块内各层拼接前面层的输出；跨越过渡层后，特征已被压缩或下采样，不能说整张网络每一层都直接收到所有更早的原始特征图。`6、12、24、16` 的最后一项也不是继续增加。

**正确理解：** 分清块内密集连接与块间过渡。Depth 或模型编号更大，也不保证在每种数据和训练预算下表现更好。

### 13.9 DenseNet 不具有比所有普通网络都更高的计算复杂度

**判断：比较对象不明确。** 原句：“整体计算复杂度仍然比普通网络高”。

密集拼接会增加激活存储和数据搬运压力，但计算量还取决于增长率、瓶颈、压缩率、网络宽深和比较对象。DenseNet 也常以参数效率为优势。

**正确理解：** 参数少、理论运算量低、训练显存少、实际运行快是不同指标。比较时固定输入、模型版本、精度和硬件，再分别测量，不能由“通道会增长”直接推出一个普遍排名。

## 14 循环神经网络

对应笔记：[循环神经网络](../public/postDir/major/深度学习/循环神经网络.md)。依据：[D2L 序列模型](https://zh-v2.d2l.ai/chapter_recurrent-neural-networks/sequence.html)、[D2L 文本预处理](https://zh-v2.d2l.ai/chapter_recurrent-neural-networks/text-preprocessing.html)、[D2L 语言模型](https://zh-v2.d2l.ai/chapter_recurrent-neural-networks/language-models-and-dataset.html)、[D2L 通过时间反向传播](https://zh-v2.d2l.ai/chapter_recurrent-neural-networks/bptt.html)、[PyTorch RNN](https://docs.pytorch.org/docs/2.14/generated/torch.nn.RNN.html)。

### 14.1 普通 RNN 传递的是隐藏状态 不一定反馈预测值

**判断：核心概念错误。** 原句：“当前的预测会作为下一步的输入”；“不断更新新的预测到h变量”。

RNN 的基本递推是把当前输入 `x_t` 与上一步隐藏状态 `h_(t−1)` 结合，得到新的隐藏状态 `h_t`，再按任务需要从隐藏状态产生预测。隐藏状态不是“上一步预测值”的另一个名字。

**正确理解：** 语言模型生成文本时，常把生成的词作为下一步输入；训练时则常输入真实的前一个词。这是输入如何构造的选择，和 RNN 必有的隐藏状态递推是两件事。

### 14.2 固定历史窗口是建模选择 不是说更早历史本来就没用

**判断：把近似假设写成事实。** 原句：“自回归只看最近的T个观测，过于久远的数据则不重要”；序列增长时线性模型“就要重新开始训练”。

有限阶自回归使用固定窗口，是主动限制使用的信息，并不证明早期信息不重要。选好固定长度窗口后，线性模型也可以持续用于更长序列，而不是每来一个观测就重新训练。

**正确理解：** 问题在于固定窗口如何选择、是否丢掉有用信息。MLP 也可以把一段历史拼成固定长度输入；它并非在任何用法下都只能看一个时刻。

### 14.3 知道准确概率分布不代表能准确知道未来的每个结果

**判断：确定的概率概念错误。** 原句：“理论上，它能完美预测后续的每一天数据”。

知道马尔可夫转移概率，意味着可以正确计算未来状态的概率分布；除非过程本身是确定的，否则不能提前知道每次实际出现哪个结果。

**正确理解：** 即使完全知道一枚公平硬币下一次正反面各占一半，仍不能保证猜中下一次结果。概率预测准确，与逐次结果预测必对，是两种不同要求。

### 14.4 时间先后和统计预测不等于已经证明因果

**判断：因果解释不严谨。** 原句：“过去决定未来”；“下雨了地一定湿”。

序列模型可学习时间上的预测关系，这本身不证明因果。现实中是否地湿还受遮挡、地面位置等条件影响，“一定”过强；棋类的马尔可夫状态也要包含轮到谁、特殊规则和必要历史信息，不能只看一张棋盘图。

**正确理解：** 把“只使用当时可获得的信息作预测”“状态足以预测未来分布”“已识别因果关系”分开理解，不要用一个直觉例子同时替代三种概念。

### 14.5 多步预测不必变直线 误差也不总按指数增长

**判断：经验现象被写成必然规律。** 原句：“就会导致预测曲线成为一条直线”；“误差随 k 指数累积”。

递归使用自己的预测可能产生误差累积，但具体形状取决于模型和过程。有的趋向常数，有的衰减、振荡或发散；“数据量不够”也不是使用自回归推理的唯一起因。

**正确理解：** 模型若是 `下一步 = a×当前值`，误差会受 a 的大小影响：绝对值小于 1 时可能衰减，大于 1 时可能放大。要结合模型的动力学分析，不能统一规定成指数增长。

### 14.6 28 个字符和未知词编号属于特定教材实现

**判断：数据集特例与原文说明混用。** 原句：“按字符切割词表只有28个字母……永远不会失忆”；“原文把 <unk> 写作空字符串 ''”。

词表大小与文本清洗规则、字符集合有关，不是所有字符级模型都有 28 个词元。未收入词表的字符仍可能成为未知词元；只要存在 `<unk>` 或清洗删除，原文也不一定可完整还原。教材的未知词元是字面字符串 `<unk>`，不应理解成空字符串。

**正确理解：** 词元化、词表映射、文本清洗是不同步骤。词频排序与 0 号未知词也是该教材词表的约定，不是所有分词器必须遵守的标准。

### 14.7 n 元语法看的是前 n−1 个词 齐普夫定律也不是统计动作

**判断：定义有误且内容缺失。** 原句：“只看前n个词，预测下一个词”；“词频分布：齐普夫定律”下面只写“统计词频率，组成词表”。

标准 n-gram 中，“当前词加上它的历史”总共 n 个词，因此预测当前词时使用前 `n−1` 个词。二元语法通常只看前一个词。

**正确理解：** 齐普夫定律描述频率与频率排名近似成反比，是数据分布的经验规律，不是“做一次统计”的另一个名字。传统统计语言模型仍有应用，也不因稀疏性就一律不能使用。

### 14.8 X 是输入 Y 才是标签

**判断：术语写反。** 原句：“所以标签X是预测数据，Y是真实结果”。

这一段示例中 X 是模型看到的输入序列，Y 是与它对应的目标序列。Y 通常取自原序列中每个输入词的下一个位置。

**正确理解：** 若 X 为 `[我, 爱, 学]`，目标 Y 可为 `[爱, 学, 习]`。所谓“偏移一位”要用这个具体对齐关系记忆，避免把“向右移动”误解成在数组前面补元素。

### 14.9 时间维度和隐藏状态形状取决于接口约定

**判断：实现特例被写成通则。** 原句：“时间步就是原输入矩阵的列”；“隐藏状态……每一行是一个样本”。

教材的数据批次可以按“批次×时间”排列，但 PyTorch RNN 输入默认常为“时间×批次×特征”，设 `batch_first=True` 后才改成“批次×时间×特征”。API 返回的最终隐藏状态还含层数和方向维。

**正确理解：** 对 `nn.RNN`，输出序列通常给出最后一层各时间步的隐藏输出；`h_n` 通常是“层数×方向数、批次、隐藏大小”的三维张量。不要仅凭变量名或二维示意图判断轴的含义。

### 14.10 完整 BPTT 不意味着一定梯度爆炸

**判断：确定的必然性错误。** 原句：“完全计算(full computation)——连乘必爆”。

长时间的雅可比矩阵连乘可能使梯度放大，也可能使其衰减，还可能在一定范围内保持稳定。是否爆炸取决于权重、激活和实际状态。

**正确理解：** 完整 BPTT 是反向传播覆盖整个展开序列；截断 BPTT 则限制反传长度，常用于控制计算和内存。截断会影响能直接学习的长距离依赖，不能只理解成不改变学习问题的省内存技巧。

## 15 现代循环神经网络

对应笔记：[现代循环神经网络](../public/postDir/major/深度学习/现代循环神经网络.md)。依据：[D2L GRU](https://zh-v2.d2l.ai/chapter_recurrent-modern/gru.html)、[D2L LSTM](https://zh-v2.d2l.ai/chapter_recurrent-modern/lstm.html)、[PyTorch GRU](https://docs.pytorch.org/docs/2.14/generated/torch.nn.GRU.html)、[PyTorch LSTM](https://docs.pytorch.org/docs/2.14/generated/torch.nn.LSTM.html)。

### 15.1 更新门为 0.3 时 原文的百分比写反了

**判断：确定错误，且与同篇前文矛盾。** 原句：“Z_t=0.3：旧状态保留 70%，新计算的信息占 30%”。

按本篇前文和 D2L、PyTorch 采用的约定，`h_t = z_t×旧状态 + (1−z_t)×候选状态`。因此 z 为 0.3 时，是 30% 的旧状态加 70% 的候选状态。

**正确理解：** 先看公式中门乘在哪一项，再解释“保留”或“更新”。有的资料会把门定义成相反的方向，不能只看 update gate 这个英文名字判断比例。

### 15.2 重置门关闭 不代表最终状态已经完全清空

**判断：门的作用范围混用。** 原句：“约等于0则旧状态被清零，退化成只看当前输入的MLP”。

重置门主要控制计算候选状态时如何使用旧状态。最终隐藏状态还会由更新门混合旧状态与候选状态；只让重置门为零，未必切断旧状态进入最终结果的那条路径。

**正确理解：** 把两步分开：先算候选，再混合状态。重置门为 1 也不意味着整个 GRU 已变成普通 RNN，因为更新门仍然存在。PyTorch 的候选式与某些教材还在重置门施加的位置上有实现差异，移植公式时要对照接口说明。

### 15.3 单位矩阵不是全一矩阵

**判断：确定的数学错误。** 原句：“单位矩阵(全1矩阵)”；“当前记忆跟旧记忆的比值约等于单位矩阵”。

单位矩阵只在主对角线上为 1，其余位置为 0。全一矩阵则每个位置都是 1，两者作用完全不同。“当前状态除以上一状态”也不是这里分析梯度的对象，应看它们之间的导数，即雅可比矩阵。

**正确理解：** 二维单位矩阵是 `[[1,0],[0,1]]`，乘向量后保持原样；全一矩阵 `[[1,1],[1,1]]` 会把两个分量相加并复制。若门恰为 1 且只看直接记忆路径，它才对应恒等传递。若门为 0.99，连乘 10000 次约为 `2.25×10⁻⁴⁴`，不是“一直完全不衰减”；真实总导数还包含门和候选对旧状态的依赖。

### 15.4 细胞状态是随样本变化的状态 不是可学习参数本身

**判断：状态和参数混淆。** 原句：“增加了一个细胞状态……也是一个可学习参数控制”；“记忆单元是细胞状态中的参数”。

LSTM 的权重和偏置是模型参数；细胞状态 c 和隐藏状态 h 是处理具体输入时逐步计算出来的状态。门使用可学习的权重来决定怎样更新状态，不代表状态里的每个数都是固定的模型参数。

**正确理解：** 换一句话，参数决定“怎样记”，状态保存“这条序列目前记住了什么”。通常的无投影 LSTM 中 c、h 尺寸可相同；使用投影等配置时不必相同，因此本篇“通常”这个限定应保留。

### 15.5 细胞状态更新后还需要生成隐藏状态

**判断：公式链没有写完整。** 原文给出 `C_t = F_t ⊙ C_(t−1) + I_t ⊙ 候选C_t`，但没有明确写出 h 的关系。

这条细胞状态公式是正确的。若读者只看这条式子，仍不知道输出门如何影响本时刻传给其他层的隐藏状态。

**正确理解：** 标准 LSTM 还有 `h_t = o_t ⊙ tanh(c_t)`。先由遗忘门和输入门更新细胞状态，再由输出门控制隐藏状态。这里的 `⊙` 是对应位置相乘，不是矩阵乘法。

## 16 附加芝士

对应笔记：[附加芝士](../public/postDir/major/深度学习/附加芝士.md)。依据：[PyTorch LayerNorm](https://docs.pytorch.org/docs/2.14/generated/torch.nn.LayerNorm.html)、[RMSNorm 论文](https://arxiv.org/abs/1910.07467)、[BatchNorm 优化机制论文](https://arxiv.org/abs/1805.11604)、[Meta Llama 官方仓库](https://github.com/meta-llama/llama-models)。

### 16.1 LayerNorm 归一化哪些轴需要看配置

**判断：概括过宽。** 原句：“对一个样本内部、跨越它的所有特征/通道算均值和方差”；括号里写“当前行”。

PyTorch 的 LayerNorm 对 `normalized_shape` 指定的最后若干维计算统计量，不是无论张量怎么排列都处理整条样本。Transformer 中常对每个词元最后的隐藏特征维归一化；图像也可以配置成对通道与空间维一起归一化。

**正确理解：** 先写清输入形状，再看配置覆盖哪几条轴。“训练和预测行为一致”说的是这一层统计量的使用方式，不代表含 Dropout 等模块的整个网络在两种模式下完全一致。可学习的仿射参数也会改变归一化后最终输出的均值和尺度。

### 16.2 RMSNorm 的加速比例不是固定常数

**判断：数字缺少实验范围。** 原句：“计算量少了约15%（少一次减法、少一个待学参数β）”。

RMSNorm 少了求均值和中心化步骤，但论文的速度提升依赖网络和实现，不是一个普遍固定的 15% 计算量结论。端到端速度还受硬件、融合算子和其他层的开销影响。

**正确理解：** 常见 RMSNorm 形式为 `x / sqrt(mean(x²)+ε) × γ`，通常不带 β。这里的 ε 同样用于数值稳定。论文给出的是特定实验中的速度表现，不能直接推算任何 LLaMA 程序都能快 15%。

### 16.3 研究证据不能写成归一化唯一有效机制的定论

**判断：结论超过证据范围。** 原句：“唯一真正起作用”的缩放；“BN 家族的有效性……而不是减均值、稳定中间分布”。

相关论文反驳或重新解释某些动机，并展示减少中心化操作仍然有效的设计，但并没有证明所有架构、任务和归一化方法中，中心化都毫无作用。BN、LN、RMSNorm 的统计轴、随机性和参数化也不同。

**正确理解：** 可以记为“归一化的效果不能只用内部协变量偏移解释；某些设计去掉中心化也有效”。不要进一步推成“缩放是所有归一化唯一有用的部分”。

### 16.4 LLaMA 的模型开放程度和商业条件要按版本区分

**判断：历史与许可范围混用。** 原句把从初代 LLaMA 到 Llama 3 统称“开源可商用”。

初代 LLaMA 的发布条件与后续 Llama 2、Llama 3 的社区许可不同；“可取得权重”“可以某些商业使用”“符合通行的开源定义”也不是同一件事。

**正确理解：** 讨论某个模型时写明版本，并看对应版本的许可和可接受使用条款。架构部分对 RMSNorm、SwiGLU、RoPE 的概括可以保留，不能用架构相似性代替许可判断。

### 16.5 SVM 小节只有名字 没有知识内容

**判断：内容缺失，不是已经写出的理论错误。** 原文只有“SVM(支持向量机):”。

读者无法从这一行知道它解决什么问题，也无法理解前文为何用它和手工特征搭配。不能把一个占位标题当作已经掌握该概念。

**正确理解：** 后续若补写，先交代最大间隔分类、支持向量和核方法分别是什么，不需要一开始就展开完整优化推导。本次按要求保留占位，不补正文。

### 16.6 利普希茨常数和雅可比的关系要注明范围

**判断：需要补数学条件。** 原句把利普希茨常数比作“最陡斜率上限”，接着介绍雅可比矩阵。

一维可导函数在合适区间内，可以用导数绝对值的上界理解这个常数；多维情形还要指定距离所使用的范数，通常对应控制雅可比的算子范数。某点的导数不能直接当成整个区域的统一上界。

**正确理解：** `f(x)=x²` 在 `[-1,1]` 上可以用 L=2 控制变化，但在整个实数轴上不存在一个有限的统一 L。讨论“平滑”或“稳定”前，必须说明在哪个范围、用什么距离。

## 18 超参数调优

对应笔记：[超参数调优](../public/postDir/major/深度学习/超参数调优.md)。依据：[Ultralytics 超参数调优指南](https://docs.ultralytics.com/guides/hyperparameter-tuning/)、[Ultralytics 训练配置](https://docs.ultralytics.com/usage/cfg/)。

这一篇对 lr0、batch、epochs 以及配置文件的基本介绍没有发现确定的概念性错误。官方指南确实使用遗传进化与变异来描述调优，不能仅凭这个说法就判为错误。需要补的是实际使用范围。

### 18.1 指标要区分单个检测框和整套检测结果

**判断：实践条件不够完整。** 原句：“IoU：当精确的目标定位至关重要时……必不可少”。

IoU 衡量两个框的重叠程度，也常参与判断预测框是否匹配真值框；单看匹配成功框的 IoU，不能完整反映漏检、误检或类别判断。Precision、Recall、F1 也受置信度阈值和匹配条件影响。

**正确理解：** 比较检测器时使用明确的 mAP 计算标准，并按任务额外查看定位、误检、漏检和速度。不能把提高某些框的 IoU 直接等同于整个检测器更好。

### 18.2 调参需要独立验证和可比较的测量条件

**判断：缺少执行说明。** 原文罗列可调参数与指标，但没有说明怎样避免挑到偶然成绩最好的配置。

反复在最终测试集上选参数，会让测试集失去独立评估意义。速度还受输入尺寸、批量大小、硬件、预热和是否计入预处理影响；更高 FPS 不一定意味着单张延迟更低。

**正确理解：** 用验证集选配置，保留测试集作最终确认；记录 Ultralytics 版本、数据划分、输入尺寸和测量条件。必要时用多个随机种子复查较好的配置。具体可调参数与搜索方式也要对照所用版本。

## 遇到术语时查这里

这些解释用于帮助阅读本报告；公式成立的具体条件仍以对应条目为准。

| 术语 | 在这份报告里怎样理解 |
| --- | --- |
| 张量、形状 | 张量可先理解为装数值的多维数组；形状说明每一维有多少元素。`N×D` 通常表示 N 条样本，每条 D 个特征。 |
| 参数、状态 | 参数是训练要学习的权重和偏置；状态是处理当前数据时计算、传递的记忆。LSTM 的细胞状态通常属于后者。 |
| batch、epoch | batch 是一次处理的一小批样本；一个 epoch 通常指完整遍历一次训练数据。 |
| 损失、梯度、学习率 | 损失衡量预测与目标的差距；梯度描述参数小幅改变时损失怎样变化；学习率控制沿更新方向走多远。 |
| 优化器、SGD、动量 | 优化器根据梯度更新参数。SGD 是常见方法；动量还保留过去更新方向的信息，所以当前梯度为零时参数也可能继续变化。 |
| 自动求导、计算图 | 自动求导根据运算关系计算梯度；计算图记录这些关系。参数被从图中分离后，损失就可能无法沿该路径给它传回梯度。 |
| logits、Softmax、独热标签 | logits 是分类器尚未归一化的得分；Softmax 将得分变成总和为 1 的概率；独热标签只在真实类别位置为 1，其余为 0。 |
| 交叉熵、KL 散度 | 交叉熵衡量用预测分布描述真实分布的代价。KL 散度衡量分布差异；它通常不对称，因此不是普通的几何距离。 |
| 归约 reduction | 把多个样本的损失合并的规则：`none` 保留各项，`sum` 求和，`mean` 求平均。训练函数与损失函数必须采用相容约定。 |
| 范数、二阶矩、方差 | 范数衡量向量或矩阵的大小；二阶矩是数值平方的平均；方差是偏离均值的平方的平均。后两者并不总相等。 |
| fan_in、fan_out | 初始化时所说的输入连接数、输出连接数。普通全连接层中通常对应输入维数和输出维数；卷积层还要考虑卷积核等设置。 |
| 雅可比、奇异值、特征值 | 雅可比把多个输出对多个输入的导数排成矩阵。奇异值描述矩阵对长度的缩放；特征值描述方阵在某些特殊方向上的作用。它们不能随意互换。 |
| buffer、state_dict | buffer 是随模块管理、但不作为普通参数列出的张量；`state_dict` 是用于保存或加载模块状态的字典。具体是否含某个 buffer 要看持久化设置。 |
| 验证集、测试集、泛化 | 验证集用于选模型和设置；测试集留作最终评估。泛化指模型面对未用于训练的新数据时的表现。 |
| QR、SVD、伪逆 | 都是处理矩阵或求解最小二乘时会遇到的方法。这里提它们，是说明求解不必强行计算一个可能不存在的普通逆矩阵，不要求先掌握其完整推导。 |
| mAP、IoU、FPS | mAP 综合评估检测器；IoU 衡量框的重叠；FPS 是每秒处理帧数。它们关注不同方面，不能互相替代。 |
